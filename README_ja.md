## 最新ニュース

### バージョン 4.1 の新機能

- **Facebookフィードのアノテーションが復活** — Facebookの最近のDOM変更による問題を解消し、ニュース投稿上でバイアスバッジが正しく表示されるようになりました  
- **ニュース検索ボタン** — バイアスバッジから直接記事に関する詳細情報を検索できます（設定で無効化可能）  
- **パフォーマンスの向上** — 効率性を高めるため、MutationObserverの処理にデバウンス機能が導入されました

### バージョン4.0の主な機能

- **スポンサー記事の制御** — フィード内のスポンサー記事を折りたたんだり非表示にしたりするオプション

- **最新の拡張機能アーキテクチャ** — Manifest v3 を採用し、Plasmoフレームワークにアップグレードされました

## はじめに

[公式メディアバイアス/ファクトチェック拡張機能](https://drmikecrowe.github.io/mbfcext/)をインストールしていただき、ありがとうございます！当社の拡張機能をご利用いただき、心より感謝申し上げます！

フェイスブックのフィードを閲覧しながら最新情報を得ましょう。私たちはインターネット上で最も包括的なメディアバイアス関連リソースです。現在、当社のデータベースには1100以上のメディアソースが登録されており、日々その数は増え続けています。フェイクニュースの出所にだまされないでください。この拡張機能は完全なオープンソースであり、ソースコードは [こちら](https://github.com/drmikecrowe/mbfcext) に掲載されています。

この拡張機能に何か問題が見つかった場合や、改善のアイデアがある場合、または単に話し合いたい場合は、[r/MediaBiasFactCheck subreddit](https://www.reddit.com/r/MediaBiasFactCheck/)をご利用いただけます。

# バージョン 1.0.15 のリリースノート

### より詳細な情報の表示に

- 報道状況：[Media Bias/Fact Check](https://mediabiasfactcheck.com)による報道分析結果  
- 参考リンク数：これは[MozのLink Equity](https://moz.com/learn/seo/what-is-link-equity)のことで、かつては「link juice」という不適切な呼称で呼ばれていました。これは、特定のリンクがあるページから別のページへ価値や権威を伝達するという考えに基づく検索エンジンのランキング要素です。この価値は、リンク元ページの権威度、トピックの関連性、HTTPステータスなど、さまざまな要因に依存します。Link Equityを伝達するリンクは、Googleをはじめとする検索エンジンがSERP上でのページのランキングを決定するために利用する多くの指標の1つです。MozのLink Equity分析結果です。  
- 人気度：2000以上あるMBFC対象サイトの中で、この数値は分析対象となったサイトがどの位置にあるかを示します。参考リンク数（Link Equity）が少ないサイトの人気度はほぼ0％となり、300万件の参考リンクがあるサイトの人気度は100％となります。この割合は、そのサイトをどの程度真剣に評価すべきかを判断するのに役立ちます。  
- 検索機能：このリンクをクリックすると、姉妹サイトである[https://factualsearch.news](https://factualsearch.news)で新しいウィンドウが開き、タグラインを検索しようとします。これにより、特定のトピックやその正確性について調査を始めるのに役立つはずです。
